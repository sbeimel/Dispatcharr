2. ❌ **SECURITY**: Missing URL encoding in `get_stream_url()` (`apps/vod/models.py:276-339`)

4. ⚠️ **WARNING**: Timeout inconsistency (HEAD: 30s, GET: 10s)

- Credential exposure in Redis (plaintext)
